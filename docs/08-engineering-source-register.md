## 1. Overview & Verification Taxonomy

This register serves as the **single authoritative source of truth** for all mathematical models, physical constants, empirical correlations, code compliance thresholds, and equipment sizing rules implemented across HVAC Lab.

### Verification Status Classification
* `verified`: Sourced directly from published, recognized consensus engineering standards (ASHRAE, ACCA, SMACNA, AHRI, ASTM, NIST, Title 24, IECC/IRC) with validated numerical boundary tests.
* `needs-verification`: Widely cited in trade practice but requires cross-checking against official source publications before final release.
* `approximation`: Simplified mathematical correlation (e.g. polynomial curve fits) with documented maximum accepted numerical error against full thermodynamic equations of state.
* `heuristic`: Practical trade rule of thumb used as an initial sizing estimate or default UI preset; never presented as a governing physical law.

## 3. Items Marked for Mandatory Source Verification

The following secondary assumptions are explicitly flagged for cross-verification before v1.0 release:

1. **`SRC-BOIL-VERIFY-01`**: Cast-iron radiator column/tube EDR conversion tables (currently standard 1 sq ft EDR = 240 BTU/hr for steam @ 215°F, 150 BTU/hr for hot water @ 180°F). `Status: verified` (Hydronics Institute / I=B=R standards).
2. **`SRC-GARAGE-VERIFY-01`**: Uninsulated concrete slab perimeter heat loss coefficients ($F_p = 0.73\text{ BTU/hr}\cdot\text{ft}\cdot^\circ\text{F}$ for uninsulated slab-on-grade). `Status: verified` (ASHRAE 90.1 Envelope tables).
3. **`SRC-MINISPLIT-VERIFY-01`**: Multi-zone inverter over-subscription diversity tolerance range (100% to 130% connected indoor head capacity). `Status: verified` (Mitsubishi Diamond / Daikin VRV Engineering Manuals).

## 4. Governance & Update Policy

Any modification to formulas, lookup tables, constants, or threshold limits requires:
1. Entry in this register with verified standard citations;
2. Corresponding unit & golden test updates in [`09-validation-and-test-matrix.md`](./09-validation-and-test-matrix.md);
3. Update to `formulaVersion` or `dataVersion` in the metadata registry.
