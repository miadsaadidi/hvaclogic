## 4. Existing-Asset-First Rule & Canonical URL Governance

### Existing-Asset-First Rule
Before creating any new URL, article, calculator, or dataset page:
> **Does HVACLogic already have a page that could satisfy this search intent?**
- **If YES**: Optimize and improve the existing page first. Do not dilute link equity or create internal competition.
- **If NO**: Create a new URL only if the intent represents a genuine, distinct engineering problem with verified topical fit and no cannibalization risk.

### Canonical URL Invariants
- **1 Primary Search Intent = 1 Canonical URL**.
- Never create separate pages for trivial keyword variations (e.g. `duct-size-calculator` vs `duct-sizing-tool` vs `ductulator`). All resolve to `/calculators/ductulator`.
- Never generate near-duplicate HVAC calculators.
- Canonical domain is strictly enforced: `https://hvaclogic.org` (non-www, HTTPS, trailing-slash consistent).

## 5. Calculators as High-Utility Search Landing Pages

Calculators are not treated as mere JavaScript widgets. Every strategic calculator is engineered as a comprehensive, authoritative search landing page:

1. **Deterministic User Purpose**: Clear headline and direct-answer summary addressing the user's immediate engineering query.
2. **Interactive Computing Engine**: 100% client-side reactive SVG/Canvas visualizer with zero lag (<50ms INP) and unit toggles (IP / SI).
3. **Transparent Mathematical Derivations**: LaTeX equations with explicit variable definitions, engineering units, and physical constants.
4. **Explicit Assumptions & Boundary Conditions**: Altitude deratings, fluid velocities, friction rates, outdoor design temperatures, and safety factors.
5. **Step-by-Step Worked Engineering Example**: Real-world calculation walkthrough with realistic input parameters and verified arithmetic.
6. **Practical Interpretation & Limitations**: Guidance on how to interpret outputs (e.g., sensible vs latent splits, friction head limits, balance point crossing) and when physical limitations apply.
7. **Governing Engineering Standards**: Verifiable citations to ASHRAE, ACCA, AHRI, SMACNA, EPA, NIST, NFPA, or IECC standards.
8. **Structured Accordion FAQs**: Genuine technical questions formatted for conversational and voice search.
9. **Contextual Internal Mesh**: Links to companion calculators in the workflow, backing research monographs, benchmark datasets, and parent pillar hubs.
10. **Validated JSON-LD Schema**: Truthful `WebApplication` structured data.

*Formula Integrity Rule*: SEO optimization must never alter calculation algorithms, constants, safety factors, or physical formulas.

## 8. Internal Linking Architecture as a Core Workstream

Internal linking is an ongoing, high-priority optimization stream designed to create a crawlable, semantically rich engineering knowledge graph:

1. **Radial Mesh Structure**:
   - **Pillar $\longleftrightarrow$ Calculators**: Bidirectional links between category hubs and their member tools.

   - **Calculator $\longleftrightarrow$ Open Dataset**: Direct links to download benchmark data arrays.
   - **Guide $\longleftrightarrow$ Calculator / Research / Dataset**: Prose-level citations and interactive companion callouts.

   - Use descriptive, intent-aligned anchor text (e.g., "Manual D duct friction loss calculator", "ASHRAE psychrometric chart calculations").
   - Strictly prohibit generic anchors ("click here", "read more", "this tool") and unnatural link stuffing.

## 11. Search-Console-First Optimization System

Google Search Console is the primary operational feedback mechanism. All diagnostic sessions prioritize real search behavior:

| GSC Signal / Scenario | Diagnostic Trigger | Autonomous Action |
| :--- | :--- | :--- |
| **Strike Distance Opportunity** | Position 4.0 – 20.0 with high impressions | Expand on-page engineering substance, add worked examples, inject contextual internal links from relevant pillar hub and guides. |
| **High Impression / Low CTR** | CTR $< 2.5\%$ on Position $< 8.0$ | Refine SEO Title and Meta Description to highlight precision, instant calculations, and governing standards compliance. |
| **Emerging Query Family** | New related queries gaining impressions | Add parameter support, specific formulas, or dedicated FAQ entries to the relevant canonical calculator. |
| **Cannibalization Signal** | 2+ URLs ranking for identical search query | Consolidate content into the primary canonical asset; align internal link anchors to the primary URL. |
| **Declining Asset** | Impressions/Clicks dropping $> 20\%$ MoM | Review algorithm freshness, verify schema integrity, check competitor SERP shifts, and update standards citations. |

*Data Integrity Invariant*: If Search Console data is unavailable or disconnected, record status as **`UNVERIFIED — requires actual Search Console evidence`**. Never fabricate query volumes, CTRs, or ranking positions.

## 13. External Distribution & Backlink Governance

External publishing is a **supporting distribution mechanism**, not the foundation of SEO:

1. **Purpose**: Reach practicing engineers, HVAC technicians, researchers, and students; build researcher identity; generate legitimate citations and referral traffic.
2. **Core-to-Spoke Flow**:
   $$\text{HVACLogic Core Page First} \longrightarrow \text{Verify} \longrightarrow \text{Select Channel} \longrightarrow \text{Adapt Content} \longrightarrow \text{Publish} \longrightarrow \text{Verify} \longrightarrow \text{Log} \longrightarrow \text{Measure}$$
3. **No Quotas**: Zero mandatory weekly quotas for external articles, bookmarks, or directory submissions.
4. **Distinct Angles**: Never cross-post duplicate copy across platforms to artificially inflate URLs. Use distinct technical angles tailored to each channel.
5. **Link Governance & Verification**:
   - Database Status: $\text{Prospect} \neq \text{Contacted} \neq \text{Published} \neq \text{Verified Backlink}$.
   - Classification: Strictly classify links as `VERIFIED DOFOLLOW`, `NOFOLLOW`, or `UNKNOWN` based on live HTML inspection.
   - Dofollow links are never required; dofollow status is never promised or presumed.
   - Never claim an external backlink produced an organic ranking change without longitudinal evidence.
